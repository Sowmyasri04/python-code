Main diff b/w procedure & oop programming:
Procedural Programming: Focuses on functions and follows a top-down approach.
OOP Programming: Focuses on objects and classes and follows a bottom-up approach.

OOPS CONCEPTS:
1. Class
2. Object
3. Inheritance
4. Polymorphism
5. Encapsulation
6. Abstraction

Real-Time OOP Examples from Websites and Social Media
1. Class: Instagram — `User` class for creating user profiles.
2. Object: Instagram — a specific user's account.
3. Inheritance: YouTube — different types of users inheriting common features from a base user class.
4. Polymorphism: WhatsApp — the `send()` action can send text messages, images, or videos.
5. Encapsulation: Facebook — protecting user account details and private information.
6. Abstraction: YouTube — watching a video without knowing how it is processed and streamed internally.
